# AI Office 3D

Три-четыре нейросети как офисные сотрудники в 3D-комнате: Claude, Claude Code, Qwen, DeepSeek.
Комикс-пузыри показывают, кто что делает; передача задачи — человечек несёт бумагу коллеге;
закрыли программу — человечек встаёт и уходит из комнаты.

Один файл `office.py`, только стандартная библиотека Python 3.14+ (3D — three.js с CDN, нужен интернет).

## Запуск

```bash
python3 office.py            # реальные модели
python3 office.py --demo     # имитация, без моделей
python3 office.py --share    # + ссылка для просмотра онлайн (нужен cloudflared)
```

Откроется http://localhost:8765.

## Что офис «видит» на компьютере (macOS)

| Кто | Присутствие | Работает |
|---|---|---|
| Claude (приложение) | запущено Claude.app | — |
| Claude Code | есть процесс `claude` | журнал `~/.claude/projects`: ход не завершён |
| Qwen | модель в LM Studio или запущен Qwen Code | `lms ps` ≠ IDLE, журнал `~/.qwen` |
| DeepSeek Harness | запущено приложение | журнал `~/.dsh/sessions`: открыт `turn` |

Читаются только типы событий и время, текст ваших диалогов не просматривается.
Передачи: к Qwen — по соединению с портом LM Studio; к Claude Code — по запуску `claude` из Harness.

## Онлайн-просмотр

`--share` поднимает туннель Cloudflare и печатает ссылку вида `https://…trycloudflare.com/?key=…`.
По ссылке доступен **только просмотр**: отправка задач и выключение работают лишь с самого компьютера,
запросы через туннель без верного ключа получают 403. Ключ меняется при каждом запуске
(или задайте свой: `OFFICE_TOKEN=...`). Не публикуйте ссылку с ключом.

Настройки сотрудников (адреса моделей, конвейер задач) — в начале `office.py`.
Ключи API в коде не хранятся: DeepSeek берётся из переменной `DEEPSEEK_API_KEY`.
